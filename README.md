## How I work

Many projects start with a problem I run into myself. I try to build something useful for people with a similar problem, even if that is a small group.

For software, I prefer local data and network access with a clear purpose. For research, I document the assumptions, preserve the validation steps and keep what is needed to reproduce an analysis. Null and inconclusive results stay alongside positive ones, including when they undermine the original idea. Known limitations stay visible.
